# svl — Android 2×2 video widget

A native Android app for Samsung home screens. Tapping its 2×2 photo widget plays MP4 sound together with fast widget image-frame updates, then restores the photo.

**Privacy:** Uploaded personal video and photo are intentionally excluded from this **public** source repository. Choose them once inside the app after installation. The personalized source bundle in the ChatGPT conversation includes the uploaded default media.

Build in Android Studio (Java 17, Android SDK 35) or download the debug APK from GitHub Actions after a successful run. Add the widget via the svl app or Samsung's Widgets menu. Launcher frame rate can vary because Android RemoteViews cannot host VideoView.
